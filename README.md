# ReBench

> AI benchmarks shouldn't be trusted. They should be reproduced.

ReBench is an open, community-run database of AI inference benchmarks.
Every number on this site is backed by a complete, machine-readable record:
model, revision, quantization, hardware, engine, software versions, benchmark
version, prompt and generation configuration, and the measured result.

There are no editorial picks. There are no averages of unknown origin. There
are runs — each one reproducible, each one traceable to a commit.

## How it works

```
LOCAL MACHINE      contributor runs the standardized runner on their own rig
     │
BENCHMARK RUNNER   fixed workload, fixed config, pinned versions
     │
RAW RESULT         one JSON file per run, validated against schema/
     │
GITHUB             submitted as a pull request into results/{family}/
     │
VALIDATION         schema check + outlier check + CI verification
     │
WEBSITE            regenerated from data/benchmarks.json
```

GitHub is the source of truth. The website is a projection of the repository.

## Repository layout

```
ReBench/
├── data/
│   └── benchmarks.json        # index generated from results/ (website input)
├── schema/
│   └── benchmark.schema.json  # JSON Schema for a single run record
├── benchmark/                 # runner + tests (planned)
├── results/                   # one directory per model family (planned)
│   ├── qwen/
│   ├── llama/
│   └── deepseek/
└── website/                   # this Next.js application
```

`data/benchmarks.json` is regenerated by CI whenever a result file lands in
`results/`. Contributors never edit it by hand.

## Current state

All records currently served are **demo data**: synthetic but plausible,
generated with `npm run generate:data` (seeded, deterministic). Every page
that displays records is labeled accordingly.

## Development

```sh
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (fully static)
npm run lint
npm run typecheck
npm run generate:data  # regenerate data/benchmarks.json
```
